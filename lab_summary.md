# Lab Summary

For this lab, I chose to refactor the provided Weekly Themed Meal Planner starter notebook rather than an existing personal project. My main goal was to improve the code structure, readability, and reliability while preserving the original functionality. I extracted reusable helper functions, separated API communication, JSON parsing, validation, and email creation into smaller components, and improved error handling with more specific exception messages and troubleshooting suggestions. One of the biggest challenges was discovering that the email button generated a new meal plan instead of reusing the displayed one. I addressed this by implementing Gradio session state. I also learned how important execution order is in Jupyter notebooks and how mocking can help test error scenarios without unnecessary API calls. Overall, the refactoring helped me better understand modular design, debugging, and reliable application testing.
